# Violet Relay 0.7.2

This maintenance update refreshes the libraries used by Violet Relay and fixes
the dependency security advisories that were blocking automated checks.

- Updates the network, certificate, media-tag, image, and build dependencies.
- Updates Qt/PySide6 to 6.12.0 and preserves existing settings and playback data.
- Includes the Apple TV casting fix already on the main branch while retaining
  built-in AirPlay TV playback.
- Updates the GitHub build actions and makes future dependency updates cover
  the actual pinned build environment.

Download `VioletRelay-0.7.2-windows-x64.zip`, verify it against
`SHA256SUMS.txt`, extract the complete folder, and run `VioletRelay.exe`.

The portable build is unsigned. Windows may show **More info -> Run anyway**.
