# xMediaPlayerx 0.4.18 public beta

This beta adds an optional, offline crypto-support interface while preserving
the project's free-software model and privacy boundaries.

## Install

1. Download `xMediaPlayerx-0.4.18-windows-x64.zip`.
2. Verify it against `SHA256SUMS.txt`.
3. Extract the complete `xMediaPlayerx` folder.
4. Run `xMediaPlayerx.exe`.

This beta is **unsigned**. Windows Defender SmartScreen may show **Windows
protected your PC**. Use **More info -> Run anyway** only after confirming the
download came from this repository and its SHA-256 matches.

In PowerShell:

```powershell
Get-FileHash .\xMediaPlayerx-0.4.18-windows-x64.zip -Algorithm SHA256
```

## Changes since 0.4.17

- Added a heart button that opens the Support development dialog.
- Added offline BTC and Ethereum/USDC QR images.
- Added one-click address copying with clear asset and network labels.
- The dialog never connects a wallet, requests credentials, or sends telemetry.
- Tips remain optional and never unlock functionality.

| ETH or USDC | Ethereum Mainnet only; USDC must be ERC-20 | `0xAd53452fB8ae492a96154D12aa671D3331AA6680` |

Check the asset and network before sending. Crypto transfers are irreversible.
The application never asks for a seed phrase or private key.

## Optional media tools

The public ZIP does not bundle or redistribute FFmpeg. On first launch,
xMediaPlayerx can download the pinned FFmpeg 8.1.2 archive directly from its
upstream Windows provider after explicit confirmation. The archive,
`ffmpeg.exe`, and `ffprobe.exe` are SHA-256 verified before use.

AirPlay support is unofficial and reverse-engineered. xMediaPlayerx is not
affiliated with, endorsed by, or certified by Apple.
