# Violet Relay 0.7.1

Violet Relay 0.7.1 is the security-maintenance replacement for 0.7.0. It keeps
the new Apple TV and built-in smart-TV AirPlay support while updating the locked
network and cryptography dependencies flagged by the release audit.

- Updated `aiohttp` from 3.14.1 to 3.14.3.
- Updated `cryptography` from 49.0.0 to 50.0.0.
- Re-ran the full unit, synthetic-media, dependency-audit, and portable-package
  checks against the patched dependency set.

Download `VioletRelay-0.7.1-windows-x64.zip`, verify it against
`SHA256SUMS.txt`, extract the complete folder, and run `VioletRelay.exe`.

The build is unsigned. Windows may require **More info -> Run anyway**.
