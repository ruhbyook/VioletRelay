# Violet Relay 0.6.1

This small visual update restores the more distinctive Violet Relay icon chosen
by the project owner: a play symbol beneath a violet-to-cyan relay arch with two
endpoint nodes.

The Windows icon, in-app artwork, repository logo, and social preview were all
regenerated from the cleaned transparent master. Playback and casting behavior
is unchanged from 0.6.0.

Download `VioletRelay-0.6.1-windows-x64.zip`, verify it against
`SHA256SUMS.txt`, extract the complete folder, and run `VioletRelay.exe`.

The build is unsigned. Windows may require **More info -> Run anyway**.

An Apple TV is optional. Violet Relay works as a standalone local audio and
video player; Apple TV hardware and private-network access are needed only when
using the casting feature.
