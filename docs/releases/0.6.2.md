# Violet Relay 0.6.2

Violet Relay is a standalone Windows 11 media player. Apple TV casting is an
optional extra, not a requirement.

This update rewrites the project overview around local playback, subtitles,
queues, resume history, direct media URLs, fullscreen mode, playback controls,
and Windows **Open with** integration. It separates the single local requirement
(Windows 11 x64) from the Apple TV and private-network requirements that apply
only when casting.

The obsolete pre-release name has also been removed from the About panel and
current public documentation.

Download `VioletRelay-0.6.2-windows-x64.zip`, verify it against
`SHA256SUMS.txt`, extract the complete folder, and run `VioletRelay.exe`.

The build is unsigned. Windows may require **More info -> Run anyway**.
