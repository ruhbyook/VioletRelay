# Violet Relay 0.6.0

The first Violet Relay public beta is a free Windows 11 media player for local
audio/video playback, direct media URLs, subtitles, queues, fullscreen viewing,
playback-speed control, and durable resume positions.

Apple TV casting is optional. When used, Violet Relay supports device discovery,
encrypted pairing, direct and converted playback, hardware-accelerated subtitle
streaming, remote transport, reconnect handling, and continuing locally.

## Install

Download `VioletRelay-0.6.0-windows-x64.zip`, verify it against
`SHA256SUMS.txt`, extract the complete folder, and run `VioletRelay.exe`.

The build is unsigned. Windows may require **More info -> Run anyway**. The
public archive does not bundle FFmpeg; Violet Relay offers to download and
verify the pinned media tools after explicit confirmation.

AirPlay integration is unofficial and Violet Relay is not affiliated with Apple.
