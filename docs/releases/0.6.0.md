# Violet Relay 0.6.0

Violet Relay is the new name for ReelFerry, the free Windows 11 media player
with Apple TV casting. This release changes the name and visual identity without
resetting the app you already configured.

## What changed

- New Violet Relay name, play-and-transfer logo, executable, and portable folder.
- Automatic migration from both ReelFerry and xMediaPlayerx.
- Existing settings, playback positions, Apple TV pairing, installed media
  tools, logs, and prepared-cast cache are retained.
- Existing Windows default-file choices keep working through compatibility
  registrations, while duplicate old names are removed from **Open with**.
- Toolbar and transport icons remain optically centered at common Windows
  scaling levels.

## Install

Download `VioletRelay-0.6.0-windows-x64-unsigned.zip`, verify it against
`SHA256SUMS.txt`, extract the complete folder, and run `VioletRelay.exe`.

The build is unsigned. Windows may require **More info → Run anyway**. The public
archive does not bundle FFmpeg; Violet Relay offers to download and verify the
pinned media tools after explicit confirmation.

This is an unofficial AirPlay integration and is not affiliated with Apple.
