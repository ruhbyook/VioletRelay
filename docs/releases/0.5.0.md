# ReelFerry 0.5.0 public beta

**ReelFerry** is the new name of xMediaPlayerx. It is the same free,
GPL-licensed Windows media player and Apple TV casting project with a clearer
identity: **Play here. Watch there.**

## Download and run

1. Download `ReelFerry-0.5.0-windows-x64.zip`.
2. Verify it with the accompanying `SHA256SUMS.txt`.
3. Extract the complete `ReelFerry` folder.
4. Run `ReelFerry.exe`.

The executable is unsigned. Windows may display **Windows protected your PC**.
Use **More info → Run anyway** only after confirming that the ZIP came from
this repository and its SHA-256 matches the published checksum.

```powershell
Get-FileHash .\ReelFerry-0.5.0-windows-x64.zip -Algorithm SHA256
```

## Upgrade behavior

The first ReelFerry launch adopts existing settings, playback positions,
encrypted Apple TV pairing credentials, installed media tools, logs, and
prepared cast files from `%LOCALAPPDATA%\xMediaPlayerx`. Large cache files are
moved locally rather than copied.

Existing Windows file associations continue to work. ReelFerry replaces visible
old-name registrations and retains a compatibility handler for file types that
Windows had already assigned to `xMediaPlayerx.Video`.

## What changed

- Renamed the application, executable, portable folder, Python package,
  diagnostics, build/release artifacts, Windows integration, and AirPlay client
  identity.
- Added the new ReelFerry icon and tagline.
- Added tested data, DPAPI credential, playback-history, and Windows registry
  compatibility across the rename.
- Isolated packaged smoke tests from actual user data and registry settings.

Playback, queueing, resume history, subtitles, GPU-accelerated conversion,
temporary HLS delivery, and modern tvOS 26 casting behavior are otherwise
unchanged from 0.4.18.

## Important notices

AirPlay support is unofficial and reverse-engineered. ReelFerry is not
affiliated with, endorsed by, or certified by Apple.

The public ZIP does not redistribute FFmpeg. ReelFerry offers to download the
pinned, SHA-256-verified tools directly from the upstream Windows provider after
the user explicitly agrees.
