# xMediaPlayerx 0.4.17 public beta

This is the first public xMediaPlayerx beta: a Windows 11 media player for local
audio/video and direct media URLs with unofficial Apple TV media casting.

## Install

1. Download `xMediaPlayerx-0.4.17-windows-x64.zip`.
2. Verify it against `SHA256SUMS.txt`.
3. Extract the complete `xMediaPlayerx` folder.
4. Run `xMediaPlayerx.exe`.

This beta is **unsigned**. Windows Defender SmartScreen may show **Windows
protected your PC**. Use **More info → Run anyway** only after confirming the
download came from this repository and its SHA-256 matches.

In PowerShell:

```powershell
Get-FileHash .\xMediaPlayerx-0.4.17-windows-x64.zip -Algorithm SHA256
```

## Optional media tools

The public ZIP does not bundle or redistribute FFmpeg. Casting, media
inspection, subtitles, and compatibility conversion require the media tools.
On first launch, xMediaPlayerx offers to download the pinned FFmpeg 8.1.2
archive directly from its upstream Windows provider (about 105 MB). The
archive, `ffmpeg.exe`, and `ffprobe.exe` are SHA-256 verified before use.

## Highlights

- Local video and long-form audio playback with durable resume positions.
- Direct MP4/MOV/HLS URLs.
- Session queue, audio/subtitle tracks, external subtitles, fullscreen, and
  playback speed.
- Apple TV discovery and DPAPI-encrypted AirPlay/Companion pairing.
- Modern tvOS 26 URL playback, stop, pause, seek, retry, and Continue Locally.
- Stream-copy HLS casting plus NVIDIA, AMD, Intel, and CPU conversion fallback.
- Burned-in subtitle streaming without waiting for a full movie conversion.
- Windows Open with/default-player integration with an explicit removal action.
- No telemetry, accounts, advertisements, DRM bypass, or site extraction.

## Compatibility

The modern AirPlay path has been physically verified on an Apple TV 4K running
tvOS 26.5 and on the maintainer's NVIDIA-equipped Windows 11 system. AMD and
Intel hardware paths have automated coverage but need broader community
hardware testing. Please use the issue template for reproducible problems.

AirPlay support is unofficial and reverse-engineered. xMediaPlayerx is not
affiliated with, endorsed by, or certified by Apple.
