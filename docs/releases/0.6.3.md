# Violet Relay 0.6.3

Violet Relay is a free and open-source Windows 11 media player with optional
Apple TV AirPlay casting for local video, MKV files, direct media URLs, and
selected subtitles.

This small guidance update makes subtitle casting easier to understand.

The AirPlay panel now reminds you to select the desired subtitle with **CC**
before pressing **Cast**. The README also explains that the selected subtitle is
built into the outgoing stream; to change it during playback, stop casting,
select the new track, and start the cast again.

Download `VioletRelay-0.6.3-windows-x64.zip`, verify it against
`SHA256SUMS.txt`, extract the complete folder, and run `VioletRelay.exe`.

The build is unsigned. Windows may require **More info -> Run anyway**.
