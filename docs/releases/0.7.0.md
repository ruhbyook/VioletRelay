# Violet Relay 0.7.0

Violet Relay is a free and open-source Windows 11 media player with optional
AirPlay casting to Apple TV and compatible smart TVs.

This release adds direct support for televisions with built-in AirPlay video.
It discovers video-capable receivers while filtering out audio-only speakers,
handles the TV pairing PIN flow, and uses the native file playback path needed
by receiver firmware that rejects Apple TV-style fragmented HLS.

Playback on built-in TVs now fills the screen, large MKV and AV1/HDR files can
start without creating a complete cast copy, and seeking replaces the active
queue item without dropping the AirPlay session. Progress overlays show the
movie's elapsed and total time instead of the system clock.

Apple TV playback also receives complete movie timelines for HDR streams,
subtitle-burned streams, and fast stream-copy/remux playback. This keeps the
progress display and seeking position accurate across every local HLS path.

Built-in-TV support remains experimental because receiver firmware varies. The
new path was exercised on a physical Hisense TV with built-in AirPlay; the
existing Apple TV protocol paths remain covered by the automated test suite.

Download `VioletRelay-0.7.0-windows-x64.zip`, verify it against
`SHA256SUMS.txt`, extract the complete folder, and run `VioletRelay.exe`.

The build is unsigned. Windows may require **More info -> Run anyway**.
