# ReelFerry icon

The ReelFerry icon is an original project asset generated by
`scripts/generate_icons.py`. Its clean geometric **R** carries a compact play
symbol between ReelFerry's violet and cyan endpoints on a midnight tile.

The generator writes the 1024 px master, the QML and GitHub PNGs, the
multi-resolution Windows ICO, and the 1280 × 640 GitHub social preview. The
letterform is deliberately optimized to remain legible at 16–32 px.

The committed icon assets are distributed under the same
GPL-3.0-or-later terms as ReelFerry.
