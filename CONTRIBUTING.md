# Contributing

Bug reports, focused fixes, tests, accessibility improvements, translations,
and documentation corrections are welcome.

## Development

Use Windows 11 and Python 3.13:

```powershell
.\scripts\bootstrap.ps1
.\scripts\test.ps1
.\scripts\run.ps1
```

The bootstrap downloads a pinned FFmpeg developer toolchain after verifying its
published SHA-256. Generated builds, media fixtures, logs, pairing data, caches,
and local configuration must not be committed.

`requirements.txt` pins the complete Windows build environment. Keep it in sync
with the dependency declarations in `pyproject.toml` when updating packages, and
run `python -m pip check` after installation. Dependabot groups related Python
updates so the declarations and installed versions can be reviewed together.

Before opening a pull request:

```powershell
.\scripts\test.ps1
$env:VIOLETRELAY_SMOKE_TEST = "1"
.\scripts\run.ps1
```

Add tests for behavior changes. Keep network, conversion, and registry work off
the QML thread. User-facing errors must be actionable and must not expose URL
queries or credentials.

## Media and protocol captures

Do not submit copyrighted media. Synthetic fixtures should be generated by the
scripts under `scripts/`. Do not commit Apple TV credentials, raw pairing
records, access tokens, private URLs, diagnostic logs, or packet captures.

## Licensing
